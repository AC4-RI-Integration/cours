# Grille OA-1 - Choisir et utiliser un outil d'édition Web

**Élément de compétence :** Élément 1 - Choisir un outil d'édition Web

**Évaluations où l'objectif est observé :** ES1 et ÉSC

| Critère | Indicateurs observables | Preuve attendue |
|---|---|---|
| Reconnaître HTML et CSS | Distingue la structure du contenu de sa présentation visuelle. | Les fichiers HTML et CSS sont identifiés correctement, reliés lorsque nécessaire et utilisés chacun pour leur rôle. |
| Choisir un environnement | Utilise un éditeur, un navigateur et les extensions appropriées. | L'environnement est configuré, la page peut être modifiée et son rendu peut être vérifié dans un navigateur. |
| Trouver des sources fiables | Consulte MDN, W3C ou une documentation reconnue. | Les sources consultées sont nommées, accessibles et directement pertinentes pour la tâche réalisée. |
| Appliquer la documentation | Transfère une information documentée dans son code. | Le code montre une utilisation correcte d'une notion recherchée et peut être expliquée à partir de la documentation consultée. |
