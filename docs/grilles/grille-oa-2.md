# Grille OA-2 - Structurer l'interface d'un site Web

**Élément de compétence :** Élément 3 - Structurer l'interface d'un site Web

**Évaluations où l'objectif est observé :** ES2 et ÉSC

| Critère | Indicateurs observables | Preuve attendue |
|---|---|---|
| Interpréter une maquette et utiliser les balises structurantes | Analyse les zones, les regroupements et la hiérarchie de la maquette, puis choisit `header`, `nav`, `main`, `section`, `article`, `footer`, etc. selon leur rôle sémantique. | Les zones de la maquette sont identifiables dans le code et la structure HTML choisie correspond à l'organisation et au sens du contenu. |
| Utiliser les balises de contenu et leurs attributs | Utilise correctement des balises de contenu, notamment `p`, `a`, `img`, `ul`, `ol`, `li`, `form`, etc., ainsi que des éléments de formulaire comme `label`, `input`, `select`, `button`, etc., avec leurs attributs essentiels, notamment `href`, `src`, `alt`, `for`, `id`, `name`, `type`, `action`, etc. | Les contenus, liens, images, listes et formulaires sont utilisables; les attributs requis sont présents, pertinents et associés aux bons éléments. |
| Construire la hiérarchie des titres | Organise les titres `h1` à `h6` selon la hiérarchie du contenu, sans saut de niveau injustifié. | La page comporte un titre principal unique, des sous-titres organisés dans un ordre logique et une hiérarchie qui reflète clairement la structure du contenu. |
| Appliquer les conventions de code | Respecte l'indentation, le nommage, les regroupements et la lisibilité du code. | Le code est correctement indenté, les éléments sont regroupés logiquement, les noms sont cohérents et le code inutile ou répétitif est évité. |
