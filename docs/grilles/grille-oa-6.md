# Grille OA-6 - Utiliser un outil de versionnage

**Élément de compétence :** Élément 2 - Utiliser un outil de versionnage

**Évaluations où l'objectif est observé :** ES2, ES3 et ÉSC

| Critère | Indicateurs observables | Preuve attendue |
|---|---|---|
| Configurer le dépôt | Initialise Git, configure la branche principale, le dépôt distant et le `.gitignore`. | Le dépôt est accessible, la branche principale et le dépôt distant sont corrects, et les fichiers à exclure sont ignorés. |
| Rédiger les messages | Décrit clairement chaque modification dans les messages de commit. | Les messages permettent de comprendre la modification réalisée sans devoir ouvrir tous les fichiers. |
| Versionner régulièrement | Crée des commits cohérents pendant le développement, chaque commit correspondant à une modification identifiable, comme une page, une section ou une fonctionnalité. | L'historique montre une progression distincte, ordonnée et récupérable; chaque commit représente une étape de travail compréhensible plutôt qu'une sauvegarde globale indistincte. |
| Gérer les paramètres | Configure les collaborateurs et les protections nécessaires. | Les personnes autorisées et les règles du dépôt correspondent au contexte du projet. |
