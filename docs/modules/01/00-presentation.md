## Présentation du module
Ce premier module servira à établir les bases dans votre apprentissage des langages d'intégration. À la fin de ce module, vous comprendez le rôle du langage HTML et CSS, votre environnement sera configuré, et vous aurez en main des sources fiables pour vous accompagner pendant votre parcours.

## Contenu

| Thème | Notions couvertes |
|---|---|
| HTML et CSS | Rôles distincts, relation entre les deux langages |
| VS Code | Interface, extensions essentielles, aperçu en direct |
| Squelette HTML | `<!DOCTYPE html>`, `<html lang>`, `<head>`, `<meta>`, `<body>` |
| Documentation | MDN, W3C, W3Schools - comment chercher efficacement |
