# Grille OA-4 - Ajuster les styles selon un guide ou une maquette

**Élément de compétence :** Élément 4 - Appliquer la présentation visuelle

**Évaluations où l'objectif est observé :** ES3 et ÉSC

| Critère | Indicateurs observables | Preuve attendue |
|---|---|---|
| Reproduire les valeurs du guide | Respecte les couleurs, la typographie et les espacements fournis. | Les valeurs visibles correspondent au guide de styles et les écarts éventuels sont justifiés. |
| Respecter la disposition | Reproduit les zones et alignements de la maquette. | Les dimensions, alignements et espacements reproduisent fidèlement la maquette dans le navigateur. |
| Maintenir la cohérence globale | Évite les valeurs arbitraires et les exceptions injustifiées. | Les pages et les composants partagent une apparence uniforme, sans styles contradictoires. |
| Utiliser des variables CSS | Regroupe les valeurs récurrentes dans des propriétés personnalisées. | Les valeurs répétées du guide sont centralisées dans des variables CSS et réutilisées dans les règles appropriées. |
