# Module 2 - Créer une première page Web

## Présentation du module
Dans ce deuxième module, vous créerez votre première page Web fonctionnelle. Vous serez introduits aux balises HTML de base ainsi qu'à des propriétés CSS afin de répondre à un mandat simple. L'objectif ici est d'être en mesure de comprendre et mettre en place la structure générale d'un projet de site Web statique. Les langages HTML et CSS seront vus en profondeur dans des modules ultérieurs.

## Contenu

| Thème | Notions couvertes |
|---|---|
| HTML | Anatomie d'une balise HTML, balises de contenu de base, imbrication et identation, validation |
| CSS | Liaison d'une feuille de style, sélecteur de balise HTML, propriétés de base, organisation et indentation |
| Démo | Créer une nouvelle page Web par étapes |
