# Grille OA-5 - Vérifier et corriger la structure et la mise en forme

**Éléments de compétence :** Éléments 3 et 4

**Évaluations où l'objectif est observé :** ES2, ES3 et ÉSC

| Critère | Indicateurs observables | Preuve attendue |
|---|---|---|
| Valider le HTML | Vérifie le code HTML avec le validateur W3C et corrige les erreurs signalées. | Le code HTML est exempt d'erreurs et présente peu d'avertissements non traités. |
| Valider le CSS | Repère les propriétés incorrectes ou redondantes et les corrige. | La feuille de style est vérifiée et les erreurs ou déclarations inutiles identifiées sont corrigées. |
| Vérifier le rendu | Teste la page dans un navigateur et corrige les problèmes visibles. | La page est testée dans le navigateur et les problèmes de disposition, de lisibilité ou de fonctionnement sont corrigés. |
| Maintenir un code lisible | Conserve une indentation, un nommage et une structure cohérents. | Le code final peut être repris par une autre personne et ne contient ni code mort ni incohérences évidentes. |
